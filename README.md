# Ex56 · Gestor Visual Matricial de Proyectos y Hábitos

Aplicación web interactiva para la gestión visual matricial de proyectos, hábitos diarios, sub-actividades por sesiones, agrupación temática e importación/exportación de datos.

## 🚀 Despliegue en GitHub Pages

La web compilada está publicada en las ramas `gb-pages` y `gh-pages`:
- **URL de la web:** [https://vortex-56.github.io/Ex56/](https://vortex-56.github.io/Ex56/)

## 🛠️ Ejecución Local

1. Instalar dependencias:
   ```bash
   npm install --legacy-peer-deps
   ```

2. Iniciar servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Compilar para producción:
   ```bash
   npm run build
   ```
